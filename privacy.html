Privacy Policy — Venture Station

Effective date: 2026-09-24

Venture Station is a small, owner-operated online business tool. This policy explains how it uses Google account data, including data accessed through Gmail and YouTube API Services.

What we access

Gmail

Venture Station accesses only the owner's own Gmail account (dogdoozystore@gmail.com), using the Gmail "gmail.modify" scope. No other person's Gmail account, and no other Google account, is accessed.

YouTube API Services

Venture Station also accesses the owner's own YouTube channel(s) (including Brand Account channels the owner controls) using the YouTube Data API, via the following scopes:

  • https://www.googleapis.com/auth/youtube.upload — to upload the owner's own video clips to the owner's own channel.
  • https://www.googleapis.com/auth/youtube.readonly — to read the owner's own channel and video status (for example, to confirm an upload completed and avoid duplicate uploads).

No other person's YouTube channel, viewer data, comments, or public user data is accessed. Only videos the owner has produced themselves, or has explicit permission to publish (for example under a creator clipping-program agreement), are uploaded.

Why we access it

Gmail access is used to read, send, and organize the business's own email — for example, retrieving sign-up or verification codes needed to operate business accounts, and reading or sending customer and campaign correspondence on the owner's behalf.

YouTube access is used solely to operate the owner's own channel: uploading the owner's own approved clips and checking their status after upload. This is an internal, single-owner tool with no other users.

How data is used and shared

Gmail and YouTube data are not sold. They are not shared with third parties, except with the AI model providers used to process Gmail content on the owner's behalf (for example, to help read, draft, or organize messages). Data received from the YouTube API is not shared with any third party, including AI model providers, and is used only to operate this internal upload tool. This data is not used for advertising and is not used to train generalized AI models.

Only minimal records needed to track the tool's own uploads are retained (video ID, upload time, and upload status). No other YouTube API response data is stored beyond what is needed for that internal tracking.

Google API Services User Data Policy

Venture Station's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Venture Station's use of the YouTube API Services is additionally subject to the YouTube Terms of Service, and Google's handling of related account data is described in the Google Privacy Policy.

Data retention and deletion

We keep only what is needed to run the tool: the OAuth credentials for the owner's own accounts, and a short record of each upload (YouTube video ID, time, and status). Data obtained through the YouTube API Services is not stored longer than necessary: it is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies. Upload records are deleted after 12 months at most.

If access is revoked (see below), stored tokens for that account are deleted within 7 days. You can request deletion of any stored data at any time by emailing dogdoozystore@gmail.com; we will delete it within 30 days.

Revoking access

You (the account owner) can revoke Venture Station's access to your Google account, including Gmail and YouTube access, at any time at myaccount.google.com/permissions.
